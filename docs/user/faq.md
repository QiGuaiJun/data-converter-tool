# 常见问题

以下问题从产品的实际界面文案、错误提示与常见使用误区整理。按主题分组，方便快速定位。

## 连接相关

### Q：为什么数据库连接失败？

**可能原因：**

1. 主机地址错误。
2. 端口错误（MySQL 默认 3306）。
3. 用户名或密码错误。
4. 数据库禁止远程连接。
5. 网络或防火墙限制。

**解决方法：** 逐项核对连接配置后重新「测试连接」。

### Q：下拉里为什么没有我想连的库？

「数据库」下拉会过滤系统库（`information_schema` / `mysql` / `sys` / `performance_schema`）。如果业务库也没出现，请确认账号对该库有访问权限。

## 导入相关

### Q：导入失败/部分行没写入？

**可能原因：** 字段类型不匹配、违反主键唯一约束、源文件某些单元格格式无法解析。

**解决方法：** 查看失败记录与错误提示，调整字段映射或改用「追加」后重试。

### Q：导入时间列为什么是文本而非日期？

MySQL 下导入时间列为 `datetime`。若自用 SQLite 或老客户端可能显示为文本；若遇类型不对，通常是目标表已有旧字段类型所致，重建表后重导。

### Q：导入模式「覆盖 / 重建」会删数据吗？

会。「覆盖」删除目标表全部记录后重新导入；「重建」删除并重建目标表。使用前务必确认数据已备份。

## 导出相关

### Q：导出的 Excel 打不开 / 乱码？

**可能原因：** 分隔符、编码与实际文件不匹配，或多项导出使用了不支持的组合。

**解决方法：** 检查目标格式与 CSV 编码设置，重新导出。

### Q：查询导出时 SQL 报错？

**可能原因：** SQL 语法错误、涉及只读以外的操作、多个查询有依赖。

**解决方法：** 先在「查询」页验证 SQL，再回到导出。

## 查询相关

### Q：结果被截断了？

**可能原因：** 返回行数过多，页面默认只展示部分结果。

**解决方法：** 在 SQL 加条件缩小范围，或用导出查看完整数据。

### Q：查询只允许哪些 SQL？

只允许 SELECT、SHOW、DESCRIBE、EXPLAIN 等只读语句，不允许修改数据库。

## 作业 / 定时任务相关

### Q：作业被跳过了？

**可能原因：** 开启了「文件有新增才执行」，但源文件相比上次没有再新增行。

**解决方法：** 如需每次执行，把执行条件改为「不启用」。

### Q：作业里找不到想要的子任务？

**可能原因：** 该任务还没保存为任务。

**解决方法：** 先到「导入 / 导出 / 查询」页保存任务，再来作业添加。

### Q：定时任务到了时间却不执行？

**可能原因：** 任务未启用，或开始 / 结束时间范围不含当前时刻，或执行条件未满足。

**解决方法：** 确认任务状态为「启用」，核对开始 / 结束时间范围。

## 部署 / 数据相关

### Q：数据不在了，比如连接配置丢了？

工具的配置与日志保存在本地 `data/imports.db`。若从克隆目录另起服务或换了数据目录，可能读到空内容。请确保运行的服务指向正确且其中的 `data/` 目录。

### Q：公网部署后重启数据会丢吗？

如果未配置持久化磁盘，云端重启后本地 SQLite 配置、上传文件和导出文件可能丢失。请在部署平台配置 `DATA_DIR` / `UPLOADS_DIR` / `EXPORTS_DIR` 指向持久化目录（详见管理员文档《配置》《备份与恢复》）。
