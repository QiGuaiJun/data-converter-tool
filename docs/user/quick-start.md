# 快速开始

数据导表工具帮助你完成「把数据从文件搬进数据库」「把数据库数据导出成文件」「按计划自动处理」等任务。本页带你走完最常用的一条链路：**把 Excel 导入 MySQL**，让你在 10 分钟内理解整个工具的使用方式。

## 在开始之前

- 你有一个可连接的数据库（本工具目前内置支持 **MySQL / MariaDB** 与 **本地 SQLite**）。
- 一条默认路径：`数据导表工具 → 新建连接（创建连接）→ 导入（执行）→ 检查结果`。

## 我要把 Excel 导入数据库——分几步？

整个工具围绕「准备源 → 指向目标 → 配置规则 → 执行 → 检查」来组织。以导入为例：

1. 准备 Excel / CSV 等源文件。
2. 新建一个数据库连接（如果还没有）。
3. 进入「导入」，选择源文件。
4. 选择目标连接与目标数据库。
5. 指定或自动生成目标表。
6. 确认字段匹配。
7. 选择导入模式。
8. 预览后执行。
9. 检查导入结果。

## 第一步：一口气跑通「Excel → MySQL」

下面每步都给出「入口 → 动作 → 预期结果」。

### 第 1 步：准备一个 Excel 文件

准备一个包含表头的 Excel（例如首行为 `姓名,金额`，下有若干行数据）。工具支持 `.xlsx / .csv / .txt / .json / .xml / .dbf` 等格式。

**预期结果：** 你能用文件选择器选中它。

### 第 2 步：新建数据库连接

进入「新建连接」，点「新增」。填写「连接名称」「主机」「端口」「用户名」「密码」「数据库」，点击「测试连接」。

**预期结果：** 提示连接测试成功。点击「保存连接」。

> 详细填法见《数据库连接》。

### 第 3 步：进入导入，选择文件

进入「导入」，点「选择文件」选中你的 Excel。页面会读取并识别列名。

**预期结果：** 页面出现字段映射与数据预览。

### 第 4 步：选择目标库与目标表

在「目标连接」下拉中选择第 2 步保存的连接，确认「MySQL」为目标类型。「目标表」选择已有表，或直接输入新表名（工具会自动建表）。

**预期结果：** 目标连接与目标库被选中，「目标表」可填。

### 第 5 步：选导入模式

在「导入模式」中选择。首次导入选「追加」最安全。

**预期结果：** 你清楚当前模式会如何影响目标表数据（详见《数据导入》的危险操作警告）。

### 第 6 步：预览并执行

点击「预览」确认解析后的数据符合预期，再点击「开始导入」。

**预期结果：** 导入完成后显示写入行数、耗时等结果。

### 第 7 步：检查结果

可在「数据表」页面查看目标表；或用「查询」执行 `SELECT` 验证数据。

**预期结果：** 数据已入库。
