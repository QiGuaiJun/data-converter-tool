# 数据查询

## 1. 功能说明

「数据查询」让你对一个已连接数据库执行只读 SQL（SELECT、SHOW、DESCRIBE、EXPLAIN），查看结果。可保存常用查询便于复用，也可把查询结果直接转到导出。

## 2. 适用场景

- 当前版本功能说明：**已实现**（数据查询完整可用）。
- 什么时候使用：
  - 快速查看某张表的数据。
  - 排查导入 / 导出后的数据是否正确。
  - 需要写一段 SQL 得到结果后导出成文件。

## 3. 操作入口

数据导表工具 → 顶栏/侧栏「查询」。

## 4. 操作步骤

### 第一步：选择连接

在「数据库连接」下拉中选择要查询的连接。

**预期结果：** 目标连接被选中。

### 第二步：编写查询

在查询输入框输入 SQL。本工具**仅允许只读 SQL**（SELECT、SHOW、DESCRIBE、EXPLAIN）。

**预期结果：** SQL 已填写。

### 第三步：执行查询

点击「执行查询」。

**预期结果：** 下方结果表格展示返回的字段与数据，并显示行数与耗时。

### 第四步：保存 / 复用（可选）

填写「查询名称」，点击「保存查询」。之后可在「已保存查询」中选择并一键回填执行。

**预期结果：** 查询被保存，之后可复用。

### 第五步：转到导出（可选）

点击「转到导出」，把当前查询结果交给导出模块生成文件。

**预期结果：** 导出页以该查询为源，可继续导出。

## 5. 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|---|---|---|---|
| 数据库连接 | 查询哪个连接 | 是 | 线上销售库 |
| SQL | 只读查询语句 | 是 | select * from sales where amount > 0 |
| 查询名称 | 保存查询时使用 | 保存时必填 | 大额订单 |

> 仅允许 SELECT、SHOW、DESCRIBE、EXPLAIN 等只读语句；不允许修改数据库。

## 6. 执行结果

- 成功：结果表格展示数据，显示行数（rowCount）与耗时（elapsedMs）。
- 结果过多时可能截断（truncated 标志），需用条件缩小范围。

## 7. 注意事项

- 只能执行只读 SQL，无法在查询页修改 / 删除数据。
- 结果过多会被截断，建议加 WHERE 条件或用导出分批。
- 保存的查询在执行时基于当前选择的连接，切换连接前请确认。

## 8. 常见问题

### Q：执行查询报语法错误？

**可能原因：** 表字段名写错、连接名拼写错误、使用到了只读之外的语句。

**解决方法：** 在「数据表」页确认表名与字段名，确保只用 SELECT/SHOW/DESCRIBE/EXPLAIN。

### Q：结果被截断了？

**可能原因：** 返回行数过多，默认只展示部分结果。

**解决方法：** 在 SQL 加条件缩小范围，或导出为文件查看完整数据。
