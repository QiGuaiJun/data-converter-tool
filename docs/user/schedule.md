# 定时任务

## 1. 功能说明

「定时任务」让数据处理自动化：在指定时间或按固定间隔自动执行某个作业 / 导入 / 导出 / 查询。

### 作业 vs 定时任务（最易混淆）

- **作业 = 做什么**：把导入、导出、查询等组合成一条流水线。
- **定时任务 = 什么时候做**：决定这条流水线在什么时刻自动触发。

例如：

```
作业（做什么）：
  ① 导入销售数据
  ② 查询昨日数据
  ③ 导出销售报表
        ↓
定时任务（何时做）：
  每天 09:00 自动执行这个作业
```

## 2. 适用场景

- 当前版本功能说明：**已实现**（定时任务完整可用）。
- 什么时候使用：
  - 每天 / 每周 / 每月到点自动导表。
  - 文件更新后自动执行数据处理。
  - 定时导出报表、定时同步入库。

## 3. 操作入口

数据导表工具 → 顶栏/侧栏「定时任务」。

## 4. 操作步骤

### 第一步：新增任务

在「定时任务」页点「新增任务」，填写「任务名称」。

**预期结果：** 打开新增定时任务对话框，标题为「新增任务」。

> 同步类型在「选择要添加的子任务类型」中当前为禁用（同步模块规划中）。

### 第二步：选择要执行的内容

在「选择要添加的子任务类型」中选择：导入 / 导出 / 查询 / 作业。若选「作业」，选择要定时执行的作业。

**预期结果：** 已选择步骤出现在已选列表。

### 第三步：设置计划时间

设置「开始时间」与「结束时间」，或点「定时设置助手」快速生成规则。

**预期结果：** 出现计划规则摘要（例如「每 1 小时轮询」「每天 09:00」）。

### 第四步：设置日志保留（可选）

勾选「保留最近 N 天的日志」并按需调整天数。

**预期结果：** 日志按天数自动清理。

### 第五步：保存并启用

点「确认」保存；在列表中对该任务点「启用任务」。

**预期结果：** 任务状态为启用，并按计划自动执行。

## 5. 参数说明

### 基础

| 参数 | 说明 | 是否必填 | 示例 |
|---|---|---|---|
| 任务名称 | 定时任务名称 | 是 | 每日销售导表 |
| 子任务类型 | 导入 / 导出 / 查询 / 作业 | 是 | 作业 |
| 开始时间 | 计划开始时间 | 是 | 2026-09-01 09:00 |
| 结束时间 | 计划结束时间 | 否（默认 2099） | 2026-12-31 |
| 保留日志 | 保留最近天数 | 否 | 3 天 |

### 定时设置助手

| 定时方式 | 含义 |
|---|---|
| 轮询 | 按固定间隔执行（秒 / 分钟 / 小时 / 天） |
| 定时 | 每天 / 每周 / 每月 / 每年，在指定时间执行 |

## 6. 执行结果

列表中每项定时任务展示：名称、状态（启用 / 禁用）、触发器、下次运行时间、上次运行时间、上次运行结果。可「查看日志」回溯最近执行情况，可「立即运行」手动触发一次。

## 7. 注意事项

- 定时任务的「作业」载体在作业列表中会以「任务名称 - 自动作业」形式出现，是为了承载步骤，可不必手动改。
- 只有启用状态的任务才会按计划执行。
- 同步类型当前为占位，选不到。

## 8. 常见问题

### Q：任务到了时间却不执行？

**可能原因：** 任务未启用，或「开始 / 结束时间」范围不含当前时刻，或执行内容条件未满足。

**解决方法：** 确认任务状态为「启用」，并核对开始 / 结束时间范围。

### Q：定时任务和作业到底有什么区别？

定时任务决定「何时执行」，作业决定「执行什么」。通常先建好作业，再建一个指向该作业的定时任务。
