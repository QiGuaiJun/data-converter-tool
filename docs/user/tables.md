# 数据表

## 1. 功能说明

「数据表」查看已连接数据库中的表对象，展示字段结构、数据预览与建表 DDL，帮助你了解表结构后再导入 / 导出 / 查询。

## 2. 适用场景

- 当前版本功能说明：**已实现**（数据表完整可用）。
- 什么时候使用：
  - 查看某张表有哪些字段、什么类型。
  - 导入前确认识别目标表结构是否正确。
  - 查询 SQL 前核对字段名。

## 3. 操作入口

数据导表工具 → 顶栏/侧栏「表」。

## 4. 操作步骤

### 第一步：选择连接

在「数据库连接」下拉中选择要查看的连接。

**预期结果：** 连接被选中，工具读取该库的数据库对象。

### 第二步：选择要查看的表

在数据库对象列表中点击一张表。

**预期结果：** 右侧展示该表的「字段结构」「数据预览」「建表 DDL」。

### 第三步：搜索表（可选）

在「搜索表」输入表名或注释过滤列表，点「刷新表列表」重新读取。

**预期结果：** 列表按关键词过滤出匹配表。

### 第四步：跳转使用（可选）

点「转到查询」或「转到导出」，把已选表带入对应模块处理。

**预期结果：** 查询 / 导出页以该表为数据源。

## 5. 参数说明

| 参数 | 说明 | 是否必填 |
|---|---|---|
| 数据库连接 | 查看哪个连接 | 是 |
| 搜索表 | 按表名或注释过滤 | 否 |
| 表 | 要查看的具体表 | 是 |

展示内容：

| 面板 | 内容 |
|---|---|
| 字段结构 | 字段名、数据类型、键、是否允许空、默认值、注释 |
| 数据预览 | 表内部分行的数据 |
| 建表 DDL | 该表的创建语句 |

## 6. 执行结果

选中表后，页面显示「已读取 N 个数据库对象」，并展示所选表的字段结构、数据预览与 DDL。

## 7. 注意事项

- 「数据表」仅查看，不在此页修改表结构。
- 数据预览只展示部分行，不代表全量数据；如需全量请用导出或查询。

## 8. 常见问题

### Q：列表为空 / 看不到表？

**可能原因：** 当前连接账号对该库没有访问权限，或过滤条件过严。

**解决方法：** 换一个有权限的连接，或清空搜索关键词后「刷新表列表」。

### Q：字段结构不准？

**说明：** 字段结构与 DDL 取自数据库元数据。若你创建了连接但字段信息来自缓存，可重新选择连接刷新。
