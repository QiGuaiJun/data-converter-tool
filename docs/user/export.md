# 数据导出

## 1. 功能说明

「数据导出」把数据库中的数据导出为文件，支持整表导出、SQL 查询结果导出。可导出为 Excel、CSV、TXT、JSON、XML、XLS、DBF 等格式。导出前可预览结果，也可把一套导出配置保存为导出任务供复用，或纳入作业。

## 2. 适用场景

- 当前版本功能说明：**已实现**（数据导出完整可用）。
- 什么时候使用：
  - 把整张表给到他人 / 生成报表。
  - 把 SQL 查询结果导出成 Excel。
  - 需要按条件筛选、指定字段、分批导出的数据交付。

## 3. 操作入口

数据导表工具 → 顶栏/侧栏「导出」。

## 4. 操作步骤

### 第一步：选择导出源

在「导出表或查询结果」区域选「选择表」「单个查询」「多个查询」「选择文件」。选「查询」时在 SQL 输入框填写查询（多个查询可用分号分隔）。

**预期结果：** 源列表显示当前选择（表名或查询）。

### 第二步：选择目标格式与名称

在「目标Excel」下拉中选择导出格式（xlsx / csv / txt / json / xml / xls / dbf）；填写「导出文件名称」与目标 Sheet、表头等。

**预期结果：** 导出目标与文件名已确定。

### 第三步：配置导出条件（可选）

在「数据」标签页按需设置过滤条件、导出字段、时间字段、文件前缀后缀、批量行数、分隔符等。

**预期结果：** 导出范围与格式细节符合预期。

### 第四步：预览

点击预览（页面提供「立即导出」前的预览动作），核对即将导出的字段与行数。

**预期结果：** 预览展示导出源与结果列。

### 第五步：立即导出

点击「立即导出」。根据浏览器能力，文件可能直接下载，或写入你指定的文件夹。

**预期结果：** 生成本地导出文件，并提示导出结果与行数。

### 第六步（可选）：保存导出任务

如需复用，填写「任务名称」并点击「保存导出任务」。该配置会作为单步导出任务保存，可在「作业」中作为子任务使用。

**预期结果：** 导出任务被保存，之后可重新打开 / 复用。

## 5. 参数说明

### 导出源与目标

| 参数 | 说明 | 是否必填 | 示例 |
|---|---|---|---|
| 导出源 | 表 / 单个查询 / 多个查询 / 文件 | 是 |  选择表 |
| SQL | 多查询用分号分隔 | 源为查询时必填 | select * from sales |
| 目标格式 | xlsx / csv / txt / json / xml / xls / dbf | 是 | xlsx |
| 导出文件名称 | 生成的文件名 | 推荐 | 销售报表2026 |
| 任务名称 | 保存导出任务时使用 | 保存任务时必填 | 每日销售导出 |

### 过滤与分列

| 参数 | 说明 | 示例 |
|---|---|---|
| 过滤条件 | 仅导出满足条件的行 | amount > 0 |
| 导出字段 | 指定字段 | id,name,amount |
| 日期字段 | 按时间范围过滤 | 略 |
| 批量行数 | 分批导出行数 | 10000 |
| CSV 编码 | CSV 输出编码 | 略 |
| 列分隔符 / 行分隔符 | 文本导出分隔符号 | , / \n |

## 6. 执行结果

- 成功：生成目标文件（下载或写入文件夹），显示导出行数与耗时。
- 失败：提示错误原因。

## 7. 注意事项

- 导出条件为空时默认导出全部行，数据量大时建议加条件或分批。
- 指定导出的文件若已存在，注意覆盖语义；必要时先备份。
- 浏览器不支持文件夹直选时，文件会通过浏览器下载。

## 8. 常见问题

### Q：导出的 Excel 打不开 / 乱码？

**可能原因：** 分隔符、编码与实际文件不匹配；多项导出用到了不支持的组合。

**解决方法：** 检查目标格式与 CSV 编码设置，重新导出。

### Q：查询导出时 SQL 报错？

**可能原因：** SQL 语法错误、涉及只读以外操作、多个查询之间有依赖。

**解决方法：** 单独在「查询」页验证 SQL 后再回到导出。
