## 二、命令执行权限怎么配（回答你的第 3 问）

### 方案 A：开腾讯云 API 权限（推荐，我能全自动完成部署）

当前连接器读取实例信息正常，但执行命令被拒，说明所用凭据**缺少命令执行相关权限**。在腾讯云控制台：

1. 进入 **访问管理（CAM）→ 用户 / 角色**，找到 WorkBuddy 连接器所用的凭据（子账号或角色）。
2. 附加策略二选一：
   - **省事**：`QcloudLighthouseFullAccess`（轻量应用服务器全读写）
   - **最小权限**：自定义策略，仅放行
     ```
     lighthouse:DescribeInstances
     lighthouse:DescribeFirewallRules
     lighthouse:CreateFirewallRules
     lighthouse:ExecuteCommand
     lighthouse:DescribeInvocationTasks
     lighthouse:DescribeCommands
     ```
3. 保存后告诉我，我重新发起一次命令执行验证（只跑 `cat /etc/os-release` 这种只读命令）。

### 方案 B：给我 SSH 通道（最快，不涉及云权限）

服务器 22 端口已对全网开放，本机有 OpenSSH 客户端。你只需之一：

- 把**私钥文件**放到本机（例如 `C:\Users\Administrator\.ssh\dc_tencent.pem`），告诉我路径与登录用户名（Ubuntu 镜像通常是 `ubuntu`）
- 或者告诉我**登录密码**（同样建议部署后修改）

我就可以用 `ssh` / `scp` 完成装环境、传代码、起服务、配反代的全部动作。

> **建议**：先走方案 B 把服务跑起来（今天就能用），再慢慢配方案 A 的 CAM 权限。

### 顺带一个安全提醒

该机 **3306 端口当前对 `0.0.0.0/0` 全网开放**。如果 MySQL 只给本机应用用，建议加规则收紧为仅 `127.0.0.1` / 内网网段；公网暴露的数据库端口是暴力破解与入侵的首要目标。

## 三、没有域名，HTTPS 怎么办（回答你的第 2 问）

公网传输登录密码**必须加密**，否则同一网络中的任何人都可能截获。没有域名时只有三条路：

| 方案 | 用户体验 | 安全 | 建议 |
|---|---|---|---|
| **① IP + HTTP（明文）** | 直接访问 `http://81.70.230.116` | ❌ 密码明文过公网 | 仅限短期内部试用 |
| **② IP + 自签证书** | 访问 `https://81.70.230.116`，浏览器**每次弹"不安全"警告**，需手动点"继续" | ✅ 传输加密 | 可用，但每个同事都要教一遍 |
| **③ 申请域名 + 备案** | `https://xxx.com` 正常绿锁 | ✅ | **推荐**，但国内 80/443 对外服务需 ICP 备案（3–20 天） |

**我的建议（按顺序执行）**：
1. **今天**：先用方案 ① 把功能跑通给内部小范围看（明确告知"这是试用，别用重要密码"）。
2. **同时**：在腾讯云申请一个便宜域名（.top/.xyz 常见活动价）+ 提交免费 ICP 备案。
3. **备案通过后**：切方案 ③，用腾讯云免费 DV 证书，80→443 跳转，登录模块正式对外开放注册。

> 若你能接受"每个同事点一次浏览器警告"，方案 ② 也可以立刻上线，不需要等备案。

## 四、服务器 MySQL 情况确认

该机 3306 已放通，但**我目前无法登录服务器确认是否已安装 MySQL**。两种可能：

- **已安装**：需提供 root 密码或一个专用账号（我会建一个只给本应用用的库与账号）
- **未安装**：部署时一并安装（推荐用 Docker 起 MySQL 8，隔离干净、易于备份）

无论哪种，部署时都会建：

```sql
create database if not exists dc_cloud character set utf8mb4 collate utf8mb4_0900_ai_ci;
create user if not exists 'dc_app'@'127.0.0.1' identified by '<部署时生成>';
grant all privileges on dc_cloud.* to 'dc_app'@'127.0.0.1';
flush privileges;
```

> **不要**让应用直接用 root 连库——应用层会执行用户上传的 SQL（查询模块已放开写权限），
> 用独立账号 + 单库授权可以把爆炸半径限制在这个库里。

## 七、域名与备案操作指引（2026-09-22 补充）

### 8.1 先做这一步：服务器续费（否则备案直接卡住）

该机 **2026-10-19 到期，只剩约 4 周**。而 ICP 备案要求备案所用云资源**剩余时长 ≥ 3 个月**
（部分省管局要求更长）——**不续费就无法提交备案**。
→ 建议直接续 1 年（也避免服务中途到期停摆）。续费后告诉我，我复核实例信息。

### 8.2 两条路线（**推荐先走 A，别为备案干等**）

| 路线 | 做法 | 拿到 HTTPS 的时间 | 访问地址形态 |
|---|---|---|---|
| **A. 不备案先用** | 域名 + 免费 DV 证书 + **改用 8443 等非 80/443 端口** | 域名注册+实名后**当天** | `https://你的域名:8443` |
| B. 备案 | A 的基础上补 ICP 备案，之后可正常用 80/443 | 备案 7–20 个工作日 | `https://你的域名` |

> 关键事实：国内未备案域名**只阻断 80/443**，其他端口不受影响。面向同事的内部工具用 8443 完全够用，
> 备案可以并行推进，不必等。

### 8.3 第一步：注册域名并实名（约 10 分钟 + 1–2 天审核）

1. 腾讯云控制台 → **域名注册** → 选 `.com` / `.cn` / `.top`（首年常见 1–30 元）。
2. 提交订单后立即做**实名认证**：企业用营业执照，个人用身份证。
3. 实名审核 **1–2 个工作日**；通过后才能提交备案（备案要求域名持有人与备案主体一致）。

### 8.4 第二步：备案（微信小程序，全程线上）

**要准备的材料**

| 材料 | 说明 |
|---|---|
| 营业执照 | 新鲜照片，在有效期内 |
| 法人身份证 | 正反面 |
| 网站负责人身份证 | 正反面；负责人可非法人（需授权） |
| 法人手机号 + 负责人手机号 | **两个不同号码**，用于核验电话 |
| 邮箱 | 接收备案通知 |
| 公章 | 《备案真实性核验单》打印后签字盖章 |
| 服务器 | 已续费、剩余时长 ≥3 个月的轻量应用服务器（就是这台） |

**流程**

1. 微信扫「腾讯云备案」小程序码 → 登录腾讯云账号。
2. **验证备案类型**：备案地区=营业执照注册地省份；类型=单位备案；填写域名；资源类型选**轻量应用服务器**并选中本机。
3. 填**主体信息**（公司全称、统一社会信用代码、法人姓名/证件号/手机号、注册地址）。
4. 填**网站负责人信息**（手机号不能与法人同号）。
5. 填**网站信息**：网站名称建议「公司简称 + 内部工具」，服务内容选「企业展示」类，前置审批项全部选「以上都不涉及」。
6. 上传材料 + 微信扫码完成**负责人视频核验**（人脸）。
7. 提交 → **腾讯云初审 1–2 个工作日**（专员会打负责人电话核实，务必接听）。
8. **短信核验（最容易翻车的一步）**：收到 **12381** 短信后，必须在 **24 小时内**点链接完成核验，**超时订单作废**。
9. **管局终审 7–20 个工作日** → 通过后收到含 ICP 备案号的短信/邮件。

**备案通过后**：30 天内到「全国互联网安全管理服务平台」做**公安备案**（免费，线上提交即可）。

## 八、权限问题的实测澄清（对应你的截图）

你截图里「访问管理 → 用户列表」**只有主账号**（账号 ID `100052287782`，无子用户）。
这说明：**连接器用的是主账号凭据，腾讯云侧的 API 权限本来就是满的**——
因此 `execute_command` 被拒**不是腾讯云 CAM 的权限不足**，而是**连接器只放行了只读类动作**（读实例、读防火墙），
写类动作（执行命令、改防火墙）需要单独授权。

三条路，按推荐顺序：

| # | 做法 | 说明 |
|---|---|---|
| 1 | **给我 SSH 通道**（最省事） | 本机已有 OpenSSH，22 端口已全网开放。把私钥放到本机并告知路径 + 用户名（Ubuntu 镜像通常 `ubuntu`），或用密码。我可以直接完成部署、配反代、起服务 |
| 2 | 在 **WorkBuddy 连接器设置**里放开该连接器的运维/命令执行授权 | 这是连接器侧的开关，不是腾讯云控制台 |
| 3 | 排查实例的「自动化助手」 | 腾讯云远程命令依赖 TAT agent，实例未安装时也无法执行；可在轻量控制台的「命令助手」里查看状态 |

> 结论：**走第 1 条最快**。CAM 侧你不需要新建子用户，也不需要改策略。
