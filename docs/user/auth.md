# 登录与账号

## 1. 功能说明

工具部署到服务器（公网 / 局域网）后，**必须先登录才能使用**。登录页是独立页面，未登录时访问任何功能页都会被自动引导过去，登录成功后再回到你原本要打开的页面。

账号分三种角色，权限由服务端逐接口校验：

| 角色 | 能做什么 |
|---|---|
| **只读**（viewer） | 查看表结构 / 数据预览 / 日志 / 已保存查询；执行**只读 SQL**（SELECT、SHOW、EXPLAIN 等） |
| **可写**（operator） | 在只读基础上：导入、预览、导出、执行写语句（DDL / DML）、管理作业与定时任务 |
| **管理员**（admin） | 全部权限，另加：连接的新建 / 修改 / 删除、账号管理、审计日志查看 |

> 本机双击 `启动导表工具.bat` 的桌面用法**不受影响**（默认不开认证，直接进主界面）。

## 2. 适用场景

- 工具部署在服务器上，多人（多市场同事）访问。
- 需要知道「谁在什么时候改了哪个库」——审计日志记录了登录、导入、导出、写 SQL、连接变更、账号变更。
- 需要限制外部同事只能看数据、不能改数据。

## 3. 操作入口

1. 浏览器打开工具地址（例如 `https://81.70.230.116`）。
2. 未登录时自动进入登录页 `/login.html`。
3. 登录成功后右上角出现用户区，显示当前账号与角色，并可「改密码」或「退出」。

## 4. 操作步骤

### 第一步：登录

在登录页填写用户名与密码，点击「登录」。

- 勾选「记住我」→ 会话保留 7 天；不勾选 → 8 小时。
- 连续输错 **5 次**会锁定该账号 **5 分钟**。

**预期结果：** 跳转到主界面（若之前访问过某个页面，会跳回那个页面）。

### 第二步：按角色使用

登录后，侧边栏只显示你有权限的入口。例如只读账号看不到「导入 / 导出 / 作业 / 定时任务 / 新建连接」，也不会出现「账号管理 / 审计日志」。

**预期结果：** 只看到自己有权使用的功能。

### 第三步：修改密码（建议首次登录后立即做）

点击右上角用户区的「改密码」，输入原密码与新密码（至少 8 位）。

**预期结果：** 提示「密码已更新」，并返回登录页用新密码重新登录；其他设备上的旧会话同时失效。

### 第四步：退出登录

点击右上角「退出」，确认后回到登录页。

**预期结果：** 当前会话作废，再访问功能页会重新要求登录。

## 5. 参数说明

| 参数 | 说明 | 是否必填 | 示例 |
|---|---|---|---|
| 用户名 | 登录账号 | 是 | zhang_san |
| 密码 | 至少 8 位 | 是 | —— |
| 记住我 | 会话从 8 小时延长到 7 天 | 否 | 勾选 |
| 邀请码 | 仅当服务端配置了 `DC_SIGNUP_CODE` 时注册需要 | 注册时视配置 | —— |

## 6. 执行结果

- 登录成功：进入主界面，右上角显示「显示名 / 角色」。
- 登录失败：登录页红字提示，文案统一为「用户名或密码不正确。」（不区分账号是否存在，避免被人探测账号）。
- 权限不足：接口返回 403，界面提示「当前账号权限不足：该操作需要「可写」角色。」

## 7. 账号管理（仅管理员）

入口：侧边栏「账号管理」。

| 操作 | 说明 |
|---|---|
| 新建账号 | 填用户名、显示名、初始密码、角色；用户名 3–32 位，只能用字母数字与 `_ . @ -` |
| **导出 CSV** | 把当前账号清单导成 CSV（UTF-8 带 BOM，Excel 直接打开不乱码）。列为：用户名 / 显示名 / 角色 / 状态 / 在线会话 / 最近登录 / 创建时间 / 创建来源 / 锁定至。**不含任何口令信息** |
| 改角色 | 行内下拉选择后点「保存角色」，立即生效 |
| 停用 / 启用 | 停用后该账号**所有已登录会话立刻失效** |
| 重置密码 | 输入新密码，旧会话同样全部失效 |
| 删除 | 删除账号并作废其全部会话 |

两条硬保护（服务端强制）：

1. **不能停用 / 删除当前登录的账号**（防止把自己锁在门外）。
2. **不能停用、降级或删除最后一名启用中的管理员**。

## 8. 审计日志（仅管理员）

入口：侧边栏「审计日志」。

- 记录内容：时间、用户、动作、对象、详情、IP、结果（成功 / 被拒绝 / 失败）。
- 可记录的动作包括：`login`、`logout`、`register`、`password`、`denied`、`csrf`、`import.run`、`export.run`、`query.write`、`query.denied`、`connection.save`、`connection.delete`、`user.create`、`user.update`、`user.delete`。
- 支持按用户 / 动作 / 结果过滤，按关键字搜索对象与详情，分页浏览。
- **默认保留 90 天**，服务启动时自动清理超期记录（可用 `DC_AUDIT_RETENTION_DAYS` 调整）。

## 9. 服务端配置（部署人员）

| 环境变量 | 说明 |
|---|---|
| `APP_AUTH_ENABLED` | 设为 `true` 开启登录（本机默认关闭） |
| `ADMIN_USER` / `ADMIN_PASSWORD` | 首个管理员的引导凭据；**两者必须同时配置**，只设 `APP_AUTH_ENABLED=true` 而漏掉 `ADMIN_PASSWORD` 会导致认证被判定为未启用而放行全部请求 |
| `DC_SIGNUP_CODE` | 注册邀请码；**留空 = 任何人都能自助注册**（默认值） |
| `DC_DEFAULT_ROLE` | 自助注册的新账号拿什么角色：`viewer`（默认，只读）／`operator`（可写）／`admin`。填错一律回落到 `viewer` |
| `DC_AUDIT_RETENTION_DAYS` | 审计保留天数，默认 90 |
| `DC_MASTER_KEY` | 数据库连接口令的加密主密钥，**必须固定**，容器重建丢失它会导致已存口令全部解不开 |

> 脚本通道（`acceptance/` 下的复跑脚本、健康检查）继续走 HTTP Basic，用 `ADMIN_USER` / `ADMIN_PASSWORD` 即可，不需要改代码。

## 10. 注意事项

- 密码以 scrypt 加盐哈希存储，数据库里查不到明文；会话 token 只存 sha256，库泄漏不等于会话泄漏。
- Cookie 为 `HttpOnly`（页面脚本读不到），HTTPS 访问时附加 `Secure`。
- 所有写操作（导入 / 导出 / 执行 SQL / 连接与账号变更）在浏览器端要求带校验头，服务端会拒绝来历不明的跨站请求——请通过界面操作，不要用浏览器插件直接构造请求。
- 公网部署请务必使用 HTTPS；自签证书的浏览器警告只影响「信任链」，传输本身仍是加密的。

## 11. 常见问题

### Q：登录后立刻又被踢回登录页？

**可能原因：** 服务器时钟偏差导致 Cookie 立即过期，或反向代理没有透传 `X-Forwarded-Proto`（HTTPS 下需要它来给 Cookie 加 `Secure`）。

**解决方法：** 检查服务器时间；确认 Nginx 配置里有 `proxy_set_header X-Forwarded-Proto $scheme;`。

### Q：同事注册了但看不到导入功能？

**可能原因：** 自助注册的账号默认是「只读」角色（`DC_DEFAULT_ROLE=viewer`），这是设计如此。

**解决方法：** 两种都行 —— ① 管理员在「账号管理」里把角色改为「可写」；
② 若这类用户是常态（例如对外开放给多个市场），把服务器 `.env` 里的 `DC_DEFAULT_ROLE` 改成 `operator` 并重启服务，
之后**新注册**的账号直接就是「可写」（已注册的账号不受影响，要单独改）。

### Q：想让「任何人打开网址就能注册并使用」，怎么配？

**解决方法：** 两项配置即可，都不需要改代码：

```text
APP_AUTH_ENABLED=true          # 开登录
DC_SIGNUP_CODE=                # 留空 = 不需要邀请码，任何人都能注册
DC_DEFAULT_ROLE=operator       # 新账号直接可写（不加这行则默认只读）
```

⚠️ 这三条合起来意味着**互联网上任何人都能注册并写入数据库**。务必同时确认：
数据库连接用的是**专用账号**（该账号只被授权单个业务库），而不是 `root`；
并定期在「审计日志」里看一眼有没有陌生账号。

### Q：执行 SQL 提示权限不足？

**可能原因：** 当前账号是「只读」，只能执行 SELECT / SHOW / EXPLAIN 这类只读语句。

**解决方法：** 让管理员提升为「可写」。

### Q：忘了管理员密码怎么办？

**解决方法：** 在服务器上设置 `ADMIN_PASSWORD` 环境变量并重启服务——只要 `_users` 里不存在**启用中的管理员**，启动时会按该变量自动补建；若管理员账号已存在，则用其他管理员账号登录后在「账号管理」里重置。
