# 作业

## 1. 功能说明

作业是把多个数据处理任务按指定顺序组合起来、一次性执行的自动化流程。你把已保存的「导入」「导出」「查询(SQL)」任务作为子任务排好顺序，工具按顺序依次执行，并记录运行日志。作业再配合「定时任务」即可到点自动执行。

### 什么是作业？

例如一个「日报生成」作业：

```
Excel导入 销售数据
   ↓
SQL查询 昨日汇总
   ↓
Excel导出 销售报表
```

作业只回答「做什么」；「什么时候做」交给定时任务。

## 2. 适用场景

- 当前版本功能说明：**已实现**（作业完整可用，支持导入/导出/查询子任务、执行条件、运行日志）。
- 什么时候使用：
  - 把「导入 → 查询 → 导出」串成一条流水线。
  - 希望通过「文件有新增才执行」或「仅在指定日期执行」等条件门控。
  - 需要反复执行、又不想每次手动点多个页面时。

## 3. 操作入口

数据导表工具 → 顶栏/侧栏「作业」。

## 4. 操作步骤

### 第一步：新增作业

在「作业」页点「新增作业」，填写「作业名称」。

**预期结果：** 打开作业编辑对话框，标题为「新增作业」。

### 第二步：添加子任务

在「选择要执行的任务」中选「类型」（导入任务 / 导出任务 / 查询(SQL)），再选具体「任务」，点「>>」加入「已选子任务」。可重复添加多个，用 ↑↓ 调整顺序。

**预期结果：** 已选子任务列表按执行顺序排列。

### 第三步：配置执行条件（可选）

点「执行条件」展开，选「条件类型」：不启用（每次都执行）、文件有新增才执行、仅在指定日期执行。

**预期结果：** 可看到条件类型与对应配置项（详见参数说明）。

### 第四步：保存

点「确认」。

**预期结果：** 作业出现在「作业列表」。

### 第五步：执行 / 查看日志

选中作业后可用「立即执行」手动触发，并在「运行日志」面板查看每次执行的结果。

**预期结果：** 作业开始执行，日志面板展示每步结果。

### 其他操作

- 「编辑作业」：修改名称、条件或子任务。
- 「复制作业」：复制为新的作业再调整。
- 「删除作业」：移除该作业。

## 5. 参数说明

### 基础

| 参数 | 说明 | 是否必填 | 示例 |
|---|---|---|---|
| 作业名称 | 作业标识 | 是 | 每日销售日报 |

### 子任务（步骤）

| 参数 | 说明 | 是否必填 |
|---|---|---|
| 类型 | 导入任务 / 导出任务 / 查询(SQL) | 是 |
| 任务 | 从已保存的对应类型任务中选择 | 是 |
| 顺序 | 用 ↑↓ 调整执行顺序 | 否 |

### 执行条件（guard）

| 条件类型 | 含义 |
|---|---|
| 不启用 | 每次都执行 |
| 文件有新增才执行 | 自动检查作业中导入任务的源文件：若相比上次没有新增行（文件未更新），整个作业跳过，无需填 SQL |
| 仅在指定日期执行 | 按日期方式门控，只在满足条件时执行 |

仅在指定日期执行下的「日期方式」：

| 方式 | 用法 |
|---|---|
| 日期范围 | 该期间每天执行 |
| 指定日期 | 只在列出的日期执行 |
| 指定星期 | 只在勾选的星期执行 |
| 指定每月几号 | 每月几号执行 |

## 6. 执行结果

- 「运行日志」展示每次执行中每个子步骤的成功 / 失败与耗时。
- 若作业满足执行条件才执行；不满足则跳过（不会报错）。

## 7. 注意事项

- 子任务只能从**已保存**的导入 / 导出 / 查询任务中选择，可先到对应模块保存任务。
- 作业与任务互相独立、互不影响：改作业不改任务，反之亦然。
- 涉及「覆盖 / 重建」导入步骤时会删数据，请在作业里谨慎安排。

## 8. 常见问题

### Q：作业被跳过了？

**可能原因：** 开启了「文件有新增才执行」，但源文件相比上次没有再新增行。

**解决方法：** 这是预期门控行为；如需每次执行，把条件改为「不启用」。

### Q：作业里怎么找不到我想要的子任务？

**可能原因：** 该任务还没保存为任务。

**解决方法：** 先到「导入 / 导出 / 查询」页把配置保存为任务，再来作业添加。
