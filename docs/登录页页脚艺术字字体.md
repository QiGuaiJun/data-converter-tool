# 登录页页脚艺术字字体

登录页页脚最后一行「让工作简单起来」用艺术字渲染（字号 18、居中），
字体在 `public/login.html` 的 `.ln-foot-vision` 里指定。

> 说明文档放在 `docs/` 而不是 `public/fonts/`：`public/` 下除 HTML 外的路径**不做登录校验**
> 会被公网直接访问，没必要把内部说明暴露出去。而**字体文件与它的许可证**放在
> `public/fonts/` 是必须的（浏览器要能取到字体；OFL 要求许可证随字体一同提供）。

```css
font-family: "字小魂沧浪行楷", "Zhi Mang Xing", "华文行楷", "STXingkai", "楷体", KaiTi, STKaiti, serif;
```

## 换成别的候选字体

同为免费商用（SIL OFL 1.1）的行书候选，本机已实测字符覆盖与体积（子集化后均约 3KB）：

| 候选 | 风格 | 原始体积 | 子集化后 |
|---|---|---|---|
| 志莽行书 Zhi Mang Xing | 行书 / 毛笔感（**当前使用**） | 3.88MB | 2.6KB |
| 马善政毛笔楷书 Ma Shan Zheng | 毛笔楷书 / 厚重 | 5.59MB | 3.2KB |
| 龙藏行书 Long Cang | 行书 / 细笔飘逸 | 4.92MB | 3.0KB |

换法（以马善政毛笔楷书为例）：

```bash
# ① 下载原始字体（github.com 直连不通时走 jsDelivr 的 GitHub 通道）
curl -L -o mashanzheng.ttf \
  "https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/mashanzheng/MaShanZheng-Regular.ttf"

# ② 子集化（自动读取 login.config.js 里的 vision 文案作为保留字符集）
./.venv/Scripts/python.exe scripts/subset_login_font.py mashanzheng.ttf \
  --out public/fonts/ma-shan-zheng.woff2

# ③ 同步下载许可证（OFL 要求随字体提供）
curl -L -o public/fonts/ma-shan-zheng-OFL.txt \
  "https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/mashanzheng/OFL.txt"

# ④ 改 public/login.html：@font-face 的 src 与 .ln-foot-vision 的 font-family 各改一行
```

> 字体路径要用 **Windows 形式**（`C:\...`）；Git-Bash 的 `/c/...` 传给 Python 会报"找不到字体文件"。

## 常见问题

**Q：改了页脚文案，新字显示成另一款字体？**
子集化只保留了旧文案的字符，新字不在字体里 → 落到回退字体。**重跑一次子集化**即可。

**Q：为什么不直接写字体名、不嵌入？**
浏览器只能用**访问者本机装了的字体**。只写字体名，等于"只有装了该字体的人能看到正确字形"，
同事和云端看到的是回退字体。要全站统一，必须嵌入。

**Q：本机打开 `/login.html` 会跳到主界面，怎么预览登录页？**
本机默认不启用登录（`APP_AUTH_ENABLED=false`），`/api/auth/me` 会把当前使用者认定为本机用户，
登录页据此直接跳回主界面。预览请用云端那份，或临时起一个 `APP_AUTH_ENABLED=true` 的实例。
