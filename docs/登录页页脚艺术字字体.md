# 登录页页脚艺术字字体（可选）

> 说明文档放在 `docs/` 而不是 `public/fonts/`：`public/` 下的文件会被公网直接访问，
> 而 `public/` 里除 HTML 外的路径不做登录校验，没必要把内部说明暴露出去。
> `public/fonts/` 目录用 `.gitkeep` 占位保证被 git 跟踪。

登录页页脚那一行「让工作简单起来」用艺术字渲染，字体在 `public/login.html` 的
`.ln-foot-vision` 里指定：

```css
font-family: "字小魂沧浪行楷", "华文行楷", "STXingkai", "楷体", KaiTi, STKaiti, serif;
```

**`public/fonts/` 这个目录是给「嵌入字体」用的。** 说明如下。

---

## 为什么要嵌入，而不是直接写字体名

浏览器只能用**访问者自己电脑上装了的字体**。所以：

- 只写字体名 → 你自己装了能看到，**同事、云端页面看到的全是回退字体**；
- 把字体文件放进这个目录并用 `@font-face` 引用 → **谁打开都长一个样**。

本项目的 `login.html` 里已经写好了 `@font-face`，指向这两个文件名（任一存在即可）：

```text
public/fonts/zixiaohun-canglang-xingkai.woff2
public/fonts/zixiaohun-canglang-xingkai.ttf
```

**目录为空时不会报错**，直接走上面的回退链（Windows 上通常是楷体 / 华文行楷）。

## ⚠️ 授权提醒（重要）

**「字小魂沧浪行楷」是收费字体**（字魂出品，个人商用 / 企业商用均需购买授权）。
各下载站点的免费下载仅限**个人学习研究**；企业物料、内部工具、产品界面都属于商业场景，
**未经授权嵌入到公司项目里属于侵权**。

所以本仓库**不包含**该字体文件。要用它，请先取得授权，例如：

- 字魂网购买「企业商用」授权 → https://izihun.com/shangyongziti/6993.html
- 拿到授权后用下面的一行命令处理即可。

若不想购买，可换**免费商用**的书法/楷体（效果接近，且可合法嵌入），例如：

## 用了授权字体后，把 9.77MB 压到几 KB

中文字体全量很大（该字体约 9.77MB、9496 字），而页脚只用 7 个字。
用仓库里的脚本做**子集化**（实测 11.23MB → 2.0KB）：

```bash
# 首次需要装依赖
./.venv/Scripts/python.exe -m pip install fonttools brotli

# 生成 public/fonts/zixiaohun-canglang-xingkai.woff2
./.venv/Scripts/python.exe scripts/subset_login_font.py "路径/字小魂沧浪行楷.ttf"
```

脚本会自动读取 `public/login.config.js` 里 `vision` 的文字作为保留字符集 ——
**改了页脚文案后重跑一次**，否则新字会落到回退字体上。

跑完刷新页面（Ctrl + F5）即可。云端要生效需提交并部署：

```bash
git add public/fonts/ && git commit -m "assets(login): 嵌入页脚艺术字字体"
```
